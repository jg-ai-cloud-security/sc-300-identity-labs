\# GitHub Project Summary



\## Project



SC-300 Day 18 – Identity Protection \& Risk-Based Access Governance



\## Description



This project reviewed Microsoft Entra Identity Protection capabilities including User Risk, Sign-in Risk, Risk Detections, Risk Policies, and Risk-Based Conditional Access integration.



The implementation demonstrated how organizations can identify suspicious authentication activity and automate security responses using Zero Trust security principles.



\## Technologies



\- Microsoft Entra ID

\- Identity Protection

\- User Risk

\- Sign-in Risk

\- Conditional Access

\- Zero Trust
