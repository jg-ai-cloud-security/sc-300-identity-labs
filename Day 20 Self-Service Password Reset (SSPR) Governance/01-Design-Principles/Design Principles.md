\# Self-Service Password Reset (SSPR) Governance



\## Design Principles



\### Zero Trust Security

Verify identity before password reset actions are allowed.



\### Secure Password Recovery

Provide secure methods for users to recover account access.



\### Strong Identity Verification

Require identity validation before password reset.



\### Least Privilege Access

Grant only the minimum access required.



\### Continuous Identity Verification

Continuously validate identity throughout account recovery.



\## Key Concepts



\### Self-Service Password Reset (SSPR)

Allows users to reset passwords without helpdesk assistance.



\### Password Reset Governance

Policies and controls that secure password reset processes.



\### Authentication Methods

Methods used to verify user identity.



\### Password Recovery

Process used to restore access to an account.



\### Identity Verification

Validation of user identity before password reset.



\### Registration Policies

Requirements for registering authentication methods.



\### Notification Policies

Notifications sent during password reset events.



\### Audit Visibility

Monitoring and tracking password reset activity.



\### Zero Trust Security

Verify identity before granting access or resetting passwords.
