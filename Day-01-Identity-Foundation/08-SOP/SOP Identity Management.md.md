\# SOP — Identity Management



\## Add User

\- Create user account

\- Assign to correct group

\- Validate access



\## Remove User

\- Disable account

\- Remove from groups

\- Remove access to:

&#x20; - Email

&#x20; - WhatsApp

&#x20; - Facebook



\## Shared Access Control

\- No shared credentials allowed

\- Access restricted to authorised roles only



\## Purpose

To standardise identity operations and reduce security risk.
