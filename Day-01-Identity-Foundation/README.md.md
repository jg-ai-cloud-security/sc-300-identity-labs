\# SC-300 — Identity \& Access Security Architecture (DR Taxi)



\## Overview



This project demonstrates the design and implementation of a cloud identity and access security architecture for a real-world transport business (DR Taxi).



The environment reflects a real operational model where bookings are managed through multiple communication channels including WhatsApp, email, phone, Facebook, and calendar scheduling.



\---





\## Project Structure



Each day follows a consistent delivery model:

\- Design (OneNote)

\- Implementation (Azure / Entra ID)

\- Documentation (GitHub)

\- Tracking (Azure DevOps)

\- Architecture (Diagrams)



\---



\## What This Project Covers



\- Identity Architecture (RBAC)

\- Access Control (MFA \& Conditional Access)

\- BYOD Security Strategy

\- Multi-tenant security design

\- Identity lifecycle and governance



\---



\## Architecture Approach



The solution uses a multi-tenant model:

\- DR Taxi tenant → Business identities (real users)

\- Tech tenant → Security controls (RBAC, Conditional Access)



This reflects real-world constraints where licensing and security separation are required.



\---



\## Day 01 — Identity Foundation



\- Designed RBAC model

\- Created business-aligned users

\- Implemented role-based groups

\- Secured access to booking channels



\---



\## Key Technologies



\- Microsoft Entra ID

\- Conditional Access

\- RBAC (Role-Based Access Control)



\---



\## Final Statement



This project demonstrates the implementation of a role-based identity architecture that secures multiple booking channels, reduces reliance on shared access, and prepares the business for scalable cloud security controls.
