\# Design Principles — Access Control \& BYOD



\## Overview

This design enforces secure access to DR Taxi systems using identity-based controls.



\## Principles Applied

\- Zero Trust

\- MFA-first authentication

\- Least Privilege

\- Conditional Access enforcement

\- Protect data, not devices (BYOD)



\## Design Approach

All access is verified through Microsoft Entra ID using Conditional Access policies and MFA.



\## Outcome

Secure and controlled access to booking channels regardless of device ownership.
