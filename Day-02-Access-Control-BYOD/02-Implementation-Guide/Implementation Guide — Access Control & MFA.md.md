\# Implementation Guide — Access Control \& MFA



\## Objective

To secure DR Taxi access using MFA and Conditional Access.



\## Implementation

\- Enabled MFA for all users

\- Created Conditional Access policies for Drivers and Admins

\- Blocked legacy authentication

\- Defined location-based access rules



\## Validation

\- MFA prompt enforced during login

\- Conditional Access policies triggered correctly



\## Business Impact

Reduced risk of account compromise and improved control over access from unmanaged devices.
