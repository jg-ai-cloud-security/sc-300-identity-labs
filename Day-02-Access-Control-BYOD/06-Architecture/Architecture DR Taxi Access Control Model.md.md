\## Overview



This architecture demonstrates how access to DR Taxi systems is controlled using Conditional Access policies.



\## Components



\- Users (Drivers, Admins, Operations, Finance)

\- Microsoft Entra ID (Identity Layer)

\- Conditional Access Policies:

&#x20; - MFA Enforcement

&#x20; - Block Legacy Authentication

&#x20; - Location Restrictions

&#x20; - BYOD Access Control

\- Booking Channels (WhatsApp, Email, Facebook, Calendar)



\## Key Insight



Access is enforced through identity and policy controls, ensuring that only authenticated and authorised users can access business systems.



\## Outcome



A Zero Trust access model that secures DR Taxi booking channels and supports BYOD environments.
