\# Implementation Guide — Identity Monitoring \& Threat Detection



\## Objective



Implement authentication monitoring and identity visibility processes to improve detection of suspicious sign-in activity within the DR Taxi environment.



\---



\# Environment



\## Tenant

Tech Tenant (Microsoft Entra ID)



\## Security Focus

\- Authentication monitoring

\- Identity visibility

\- Threat detection

\- Suspicious sign-in analysis



\---



\# Implementation Steps



\## Step 1 — Access Microsoft Entra ID



\- Sign in to Microsoft Entra Admin Center

\- Navigate to:

&#x20; Monitoring → Sign-in logs



\### Purpose

Access authentication activity and sign-in visibility data.



\---



\## Step 2 — Review Sign-In Activity



\- Review successful sign-ins

\- Review failed sign-ins

\- Analyse authentication events



\### Purpose

Identify suspicious or abnormal authentication behaviour.



\---



\## Step 3 — Review Administrative Sign-Ins



\- Filter administrative user activity

\- Review privileged authentication events



\### Purpose

Improve visibility into privileged account usage.



\---



\## Step 4 — Investigate Failed Authentication Events



\- Analyse failed sign-ins

\- Review login patterns

\- Investigate suspicious authentication attempts



\### Purpose

Support threat detection and authentication analysis.



\---



\# Validation



\- Sign-in visibility confirmed

\- Failed login analysis completed

\- Administrative sign-in monitoring reviewed



\---



\# Business Outcome



Improved authentication visibility and strengthened identity monitoring within the DR Taxi environment.



\---



\# Security Benefits



\- Improved authentication visibility

\- Better suspicious sign-in detection

\- Enhanced identity monitoring

\- Improved threat investigation capability



\---



\# Constraints



Some advanced Microsoft Entra Identity Protection features may require additional licensing.



\---



\# Evidence Captured



\- Sign-in logs

\---



\# Conclusion



Identity monitoring improves visibility into authentication activity and strengthens security operations through better threat detection and investigation capabilities.
