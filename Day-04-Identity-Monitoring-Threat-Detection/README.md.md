\# SC-300 — Identity Monitoring \& Threat Detection (DR Taxi)



This project demonstrates the implementation of identity monitoring and authentication visibility controls within the DR Taxi environment.



The implementation focuses on:

\- Authentication monitoring

\- Sign-in visibility

\- Failed login analysis

\- Administrative sign-in monitoring

\- Threat detection processes



The solution improves identity visibility and strengthens security operations through authentication monitoring and investigation workflows.
