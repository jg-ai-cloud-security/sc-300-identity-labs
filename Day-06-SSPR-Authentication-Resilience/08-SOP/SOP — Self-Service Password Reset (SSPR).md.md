\# SOP — Self-Service Password Reset (SSPR)



\## Password Recovery Process

\- User initiates password reset

\- Identity verification is performed

\- MFA validation is completed

\- Password reset is authorised

\- User regains secure account access



\## Authentication Verification

\- Validate registered authentication methods

\- Confirm MFA verification

\- Review identity validation requirements



\## Purpose

Improve secure password recovery and strengthen authentication resilience within the DR Taxi environment.
