\# SC-300 — Self-Service Password Reset (SSPR) \& Authentication Resilience (DR Taxi)





This project demonstrates the implementation of Self-Service Password Reset (SSPR) and authentication resilience controls within the DR Taxi environment.



The implementation focuses on:

\- Secure password recovery

\- Authentication resilience

\- Identity verification

\- MFA validation

\- Password recovery visibility



The solution improves secure account recovery processes and strengthens authentication resilience aligned with Zero Trust identity security principles.
