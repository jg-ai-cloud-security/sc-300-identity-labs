\# SC-300 — Device Compliance \& BYOD Security (DR Taxi)



This project demonstrates the implementation and governance review of Microsoft Intune device compliance and BYOD security controls within the DR Taxi environment.



The implementation focuses on:

\- Device compliance

\- BYOD governance

\- Conditional Access integration

\- Endpoint security visibility

\- Zero Trust identity protection



The solution improves secure resource access and strengthens endpoint governance aligned with Microsoft security best practices.
