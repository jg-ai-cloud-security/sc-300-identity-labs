\# SC-300 Day 08 — Identity Governance Architecture



\## Overview



This architecture demonstrates how Microsoft Entra ID governance controls improve RBAC visibility, lifecycle governance awareness, and least privilege access management within the DR Taxi environment.



\---



\# Components



\## Users

\- Drivers

\- Admins

\- Operations

\- Finance



\## Microsoft Entra ID

Provides centralised identity and governance management.



\## RBAC Governance

Controls administrative access visibility and privileged role governance.



\## Access Reviews

Improves governance visibility and user access recertification awareness.



\## Lifecycle Governance

Supports onboarding, role transition, and offboarding governance awareness.



\## Identity Governance Controls

Improves governance maturity and strengthens identity security visibility.



\## Least Privilege Access

Reduces excessive permissions and improves access governance alignment.



\---



\# Security Flow



Users authenticate through Microsoft Entra ID.



RBAC governance and access review visibility improve administrative access awareness.



Lifecycle governance improves onboarding and offboarding governance visibility.



Identity governance controls strengthen least privilege access management and support Zero Trust identity security principles.



\---



\# Governance Outcome



The architecture improved visibility into:

\- Administrative access governance

\- Identity lifecycle governance

\- RBAC governance

\- Access review awareness

\- Least privilege access management



\---



\# Conclusion



Identity governance improves organisational visibility into user access management and strengthens enterprise identity protection aligned with Zero Trust security principles.
