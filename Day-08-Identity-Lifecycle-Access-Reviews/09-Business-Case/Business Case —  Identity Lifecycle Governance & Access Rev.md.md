\# Business Case — Identity Lifecycle Governance \& Access Reviews



\## Problem



Without governance and access review controls, excessive permissions, inactive accounts, and unmanaged administrative access may increase organisational security risk.



Limited visibility into user lifecycle governance may also create challenges when validating least privilege access across the organisation.



\---



\## Solution



Review and document Microsoft Entra ID governance controls including:

\- RBAC visibility

\- Access reviews

\- Lifecycle governance

\- Administrative role governance

\- Least privilege access management



The implementation focused on improving identity governance visibility and strengthening governance awareness aligned with Zero Trust identity security principles.



\---



\## Security Benefits



The implementation improved visibility into:

\- Administrative access governance

\- User lifecycle governance

\- RBAC visibility

\- Access review awareness

\- Least privilege governance alignment



\---



\## Constraints



Some advanced Microsoft Entra ID Governance features including:

\- Automated access reviews

\- Lifecycle workflow automation

\- Advanced governance automation



require additional Microsoft Entra ID Governance licensing.



The implementation was therefore completed as a governance visibility and architecture assessment aligned with Microsoft 365 Business Premium capabilities.



\---



\## Governance Outcome



The review process improved visibility into:

\- Identity governance architecture

\- User lifecycle governance

\- RBAC governance controls

\- Access review planning

\- Governance workflow awareness



\---



\## Business Outcome



The implementation strengthened governance visibility and improved identity security awareness within the DR Taxi environment.



The solution supports:

\- Zero Trust identity protection

\- Least privilege access management

\- Governance maturity

\- Identity lifecycle security

\- Administrative access visibility



\---



\## Conclusion



Identity governance and access review visibility improve organisational security posture by strengthening RBAC governance, reducing excessive access risk, and improving lifecycle governance awareness across the organisation.
