\# SC-300 — Identity Lifecycle Governance \& Access Reviews (DR Taxi)



This project demonstrates identity lifecycle governance and RBAC access review security controls implemented within the DR Taxi environment.



The implementation focuses on:

\- Identity governance

\- Access reviews

\- RBAC visibility

\- Joiner/Mover/Leaver governance

\- Least privilege access control



The solution improves user access visibility and strengthens identity governance aligned with Zero Trust identity security principles.
