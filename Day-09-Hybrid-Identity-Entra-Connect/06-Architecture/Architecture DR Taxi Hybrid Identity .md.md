\# SC-300 Day 09 — Hybrid Identity Governance Architecture



\## Overview



This architecture demonstrates how hybrid identity synchronisation and Microsoft Entra Connect improve identity integration and governance visibility within the DR Taxi environment.



The implementation focuses on:

\- Hybrid identity governance

\- Synchronisation visibility

\- Cloud identity integration

\- RBAC awareness

\- Identity governance planning



\---



\# Components



\## Users

\- Drivers

\- Operations

\- Finance

\- Administrators



\## On-Premises Active Directory

Provides centralised identity management for hybrid environments.



\## Microsoft Entra Connect

Synchronises on-premises identities with Microsoft Entra ID.



\## Cloud Sync

Improves hybrid identity synchronisation visibility and governance awareness.



\## Microsoft Entra ID

Provides cloud identity management and governance visibility.



\## Hybrid Identity Governance

Improves synchronisation governance and identity lifecycle visibility.



\## Secure Cloud Access

Supports secure identity integration and cloud authentication visibility.



\---



\# Security Flow



Users authenticate through hybrid identity integration between on-premises Active Directory and Microsoft Entra ID.



Microsoft Entra Connect and Cloud Sync improve synchronisation visibility and hybrid identity governance awareness.



RBAC visibility and governance reviews strengthen identity security planning and least privilege awareness.



\---



\# Security Benefits



\- Improved hybrid identity visibility

\- Improved synchronisation awareness

\- Improved identity governance planning

\- Improved cloud identity integration

\- Strengthened RBAC governance awareness



\---



\# Constraints



Some advanced synchronisation and identity governance capabilities may require additional Microsoft Entra licensing depending on business requirements.



The implementation was documented using Microsoft 365 Business Premium hybrid identity visibility capabilities.

\# Outcome



The implementation improved hybrid identity governance awareness and strengthened synchronisation visibility within the DR Taxi environment.
