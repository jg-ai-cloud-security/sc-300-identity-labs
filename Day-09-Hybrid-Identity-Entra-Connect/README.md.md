\# SC-300 — Hybrid Identity \& Microsoft Entra Connect (DR Taxi)



This project demonstrates hybrid identity synchronisation and Microsoft Entra Connect governance controls implemented within the DR Taxi environment.



The implementation focuses on:

\- Hybrid identity governance

\- Identity synchronisation

\- Authentication consistency

\- Microsoft Entra Connect visibility

\- Zero Trust identity security



The solution improves centralised identity management and strengthens authentication governance across cloud and on-premises environments.
