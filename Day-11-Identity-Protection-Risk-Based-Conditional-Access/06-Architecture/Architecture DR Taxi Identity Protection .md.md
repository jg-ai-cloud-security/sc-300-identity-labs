\# SC-300 Day 11 — Identity Protection \& Risk-Based Conditional Access Architecture



\## Overview



This architecture demonstrates how Microsoft Entra ID Identity Protection and adaptive Conditional Access improve identity risk visibility and strengthen Zero Trust access governance within the DR Taxi environment.



The implementation focuses on:

\- Identity Protection visibility

\- Risk detection awareness

\- Risky sign-in governance

\- User risk monitoring

\- Adaptive Conditional Access

\- Zero Trust identity protection



\---



\# Components



\## Users

\- Drivers

\- Operations

\- Finance

\- Administrators



\## Microsoft Entra ID

Provides cloud identity management and authentication governance visibility.



\## Identity Protection

Improves visibility into risky sign-ins, compromised accounts, and adaptive identity risk governance.



\## Risk Detection

Monitors suspicious authentication activity and compromised account indicators.



\## Risky Sign-ins \& Risky Users

Provides governance visibility into risky authentication behaviour and compromised identity awareness.



\## Risk-Based Conditional Access

Strengthens adaptive access governance and authentication security planning.



\## Adaptive Authentication (MFA)

Improves authentication security and supports Zero Trust access governance.



\## RBAC Governance

Strengthens least privilege visibility and identity governance planning.



\## Secure Resource Access

Supports secure access to organisational resources through adaptive identity governance controls.



\---



\# Security Flow



Users authenticate through Microsoft Entra ID.



Identity Protection and risk detection monitor authentication behaviour and improve compromised account visibility.



Risk-based Conditional Access and adaptive authentication strengthen secure access governance aligned with Zero Trust identity protection principles.



RBAC governance visibility improves least privilege access planning and identity governance awareness.
