\# Executive Summary — Identity Protection \& Risk-Based Conditional Access



\## Overview



This implementation reviewed identity protection visibility and adaptive Conditional Access governance within the DR Taxi environment using Microsoft Entra ID.



The implementation focused on:

\- Identity protection visibility

\- Risky sign-ins awareness

\- User risk governance

\- Adaptive Conditional Access

\- Identity risk visibility

\- Zero Trust identity protection



\## Technologies Reviewed



\- Microsoft Entra ID

\- Identity Protection

\- Risky Sign-ins

\- Conditional Access

\- RBAC Governance

\- Adaptive Authentication



\## Security Benefits



\- Improved identity protection visibility

\- Improved adaptive access awareness

\- Improved identity risk governance visibility

\- Improved Zero Trust security awareness

\- Strengthened compromised account visibility



\## Constraints



Some advanced identity protection and adaptive Conditional Access capabilities may require Microsoft Entra ID P2 licensing depending on organisational requirements.



The implementation was documented using Microsoft 365 Business Premium identity governance visibility capabilities.



\## Outcome



The implementation improved identity protection awareness and strengthened adaptive access governance visibility within the DR Taxi environment.



This project demonstrates enterprise-aligned identity protection governance and adaptive Conditional Access planning using Microsoft Entra ID.
