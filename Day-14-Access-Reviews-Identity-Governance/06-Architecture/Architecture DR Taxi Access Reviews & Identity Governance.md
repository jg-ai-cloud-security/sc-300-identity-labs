\# SC-300 Day 14 — Access Reviews \& Identity Governance Architecture



\## Overview



This architecture demonstrates how Identity Governance and Access Reviews improve lifecycle governance visibility and strengthen secure access review controls within the DR Taxi environment.



\## Components



\- Users

\- Microsoft Entra ID

\- Identity Governance

\- Access Reviews

\- Guest Access Reviews

\- Approval Workflow

\- Governance Monitoring



\## Security Flow



Users authenticate through Microsoft Entra ID before governance review controls are applied.



Identity Governance and Access Reviews improve visibility into user access, guest accounts, lifecycle governance, and secure collaboration controls.



\## Outcome



Improved governance visibility and strengthened lifecycle governance awareness within the DR Taxi environment.
