\# SC-300 Day 14 — Access Reviews \& Identity Governance



\## Overview



This implementation reviewed Access Reviews and Identity Governance controls within the DR Taxi environment using Microsoft Entra ID.



The implementation focused on:

\- Identity governance visibility

\- Access review governance

\- Guest access governance

\- Lifecycle governance

\- Governance workflow visibility

\- Zero Trust identity governance controls



\---



\# Business Scenario



DR Taxi requires secure identity governance and periodic access reviews to reduce excessive permissions, improve lifecycle governance, and minimise unauthorised access exposure across organisational identities and guest accounts.



\---



\# Technologies Reviewed



\- Microsoft Entra ID

\- Identity Governance

\- Access Reviews

\- External Identities

\- MFA

\- Conditional Access

\- Governance Monitoring



\---



\# Implementation Summary



The implementation reviewed:

\- Identity governance visibility

\- Access review governance

\- Lifecycle governance controls

\- Guest access governance

\- Governance workflow visibility

\- Secure access review monitoring



The implementation validated governance visibility for secure identity lifecycle management and strengthened Zero Trust governance awareness.



\---



\# Security Benefits



\- Improved identity governance visibility

\- Improved access review awareness

\- Improved lifecycle governance visibility

\- Improved guest access governance

\- Strengthened Zero Trust identity governance



\---



\# Business Risk



Unreviewed user access and unmanaged guest accounts may increase the risk of excessive permissions, stale access, insider threats, and unauthorised collaboration exposure.



\---



\# Recommendation



Implement periodic access reviews, lifecycle governance monitoring, and guest access governance controls to strengthen secure identity governance visibility.



\---



\# Zero Trust Alignment



\- Verify explicitly

\- Use least privilege access

\- Assume breach

\- Continuously review identity access
