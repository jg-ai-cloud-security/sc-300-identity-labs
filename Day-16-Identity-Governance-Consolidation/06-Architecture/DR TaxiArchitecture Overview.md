\## Design Principles



\- Zero Trust Governance

\- Least Privilege Access

\- Lifecycle Automation

\- Governance Visibility





This architecture demonstrates how Microsoft Entra ID governance controls work together to improve privileged access governance, lifecycle governance, and secure identity management within the DR Taxi environment.



The implementation strengthens Zero Trust identity governance by combining PIM, Access Reviews, and Entitlement Management into a unified governance model.
