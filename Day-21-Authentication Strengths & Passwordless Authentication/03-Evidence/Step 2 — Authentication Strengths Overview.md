\## Evidence 2 – Authentication Strengths Overview



Authentication Strengths were reviewed within Microsoft Entra ID.



Authentication Strengths allow administrators to define which authentication methods users must use when accessing protected resources through Conditional Access policies.



The following built-in Authentication Strengths were identified:



\- Multifactor Authentication

\- Passwordless MFA

\- Phishing-Resistant MFA



These Authentication Strengths support Zero Trust principles by enforcing stronger authentication requirements and reducing the risk of credential compromise.
