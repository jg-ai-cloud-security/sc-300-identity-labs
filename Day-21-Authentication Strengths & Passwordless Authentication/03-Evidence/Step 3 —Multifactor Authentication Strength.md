\## Evidence 3 – Multifactor Authentication Strength



The built-in Multifactor Authentication Authentication Strength was reviewed.



This Authentication Strength provides medium assurance authentication and supports multiple approved authentication methods.



Supported methods include:



\- Windows Hello for Business

\- FIDO2 Passkeys

\- Microsoft Authenticator

\- Temporary Access Pass

\- Certificate-Based Authentication

\- OATH Tokens



This Authentication Strength can be enforced through Conditional Access policies to improve account security and reduce the risk of unauthorized access.
