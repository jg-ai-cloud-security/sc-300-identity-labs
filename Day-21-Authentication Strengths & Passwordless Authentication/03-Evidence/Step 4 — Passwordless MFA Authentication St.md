\# Evidence 4 – Passwordless MFA Authentication Strength



\## Purpose



Review the built-in Passwordless MFA Authentication Strength available within Microsoft Entra ID.



\## Findings



The Passwordless MFA Authentication Strength was reviewed within Microsoft Entra ID Authentication Methods.



This Authentication Strength is classified as a High Assurance Authentication Strength and is designed to eliminate traditional password usage by leveraging cryptographic authentication methods.



The following authentication methods were available:



\* Windows Hello for Business

\* Passkeys (FIDO2)

\* Certificate-Based Authentication (Multifactor)

\* Microsoft Authenticator (Phone Sign-in)



\## Security Benefits



\* Eliminates password dependency

\* Reduces credential theft risks

\* Protects against phishing attacks

\* Improves user sign-in experience

\* Supports Zero Trust Security principles



\## Business Impact



Implementing Passwordless MFA helps organizations strengthen identity security while reducing password-related support requests and improving user productivity.



\## Outcome



The Passwordless MFA Authentication Strength provides stronger authentication assurance than traditional password-based methods and supports modern identity protection strategies within Microsoft Entra ID.
