\## Authentication Strengths Investigation



Authentication Strengths provide organizations with the ability to enforce approved authentication methods through Conditional Access policies.



Three built-in Authentication Strengths were available:



\### Multifactor Authentication

Supports approved MFA methods including Microsoft Authenticator and other supported factors.



\### Passwordless MFA

Allows users to authenticate without traditional passwords using methods such as Windows Hello for Business, Passkeys, and FIDO2 Security Keys.



\### Phishing-Resistant MFA

Provides the highest level of identity protection and helps prevent credential theft through phishing attacks.



Authentication Strengths are a key component of Microsoft's Zero Trust identity strategy.
