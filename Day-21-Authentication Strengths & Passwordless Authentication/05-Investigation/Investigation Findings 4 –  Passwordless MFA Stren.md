\## Investigation Findings 3 – Passwordless MFA Strength Review



The Passwordless MFA Authentication Strength was reviewed within Microsoft Entra ID.



This Authentication Strength provides high assurance authentication by using cryptographic credentials instead of traditional passwords.



Supported authentication methods include:



\- Windows Hello for Business

\- Passkeys (FIDO2)

\- Certificate-Based Authentication

\- Microsoft Authenticator Phone Sign-in



Key Benefits:



\- Eliminates password dependency

\- Reduces phishing attacks

\- Improves user experience

\- Supports Zero Trust identity verification

\- Provides stronger authentication assurance



Passwordless MFA strengthens identity protection by removing passwords from the authentication process and replacing them with more secure authentication methods.
