\# Executive Summary



\## Project Title



SC-300 Day 21 – Authentication Strengths \& Passwordless Authentication



\## Executive Overview



This project focused on Authentication Strengths and Passwordless Authentication within Microsoft Entra ID. The objective was to understand how organizations can strengthen identity security by reducing reliance on traditional passwords and implementing phishing-resistant authentication methods.



Authentication Strengths provide administrators with the ability to define and enforce approved authentication methods through Conditional Access policies. This ensures users authenticate using methods that meet organizational security requirements.



The project reviewed several passwordless technologies including Microsoft Authenticator, Windows Hello for Business, FIDO2 Security Keys, and Passkeys. These technologies help reduce credential theft risks while improving the user authentication experience.



\## Business Challenge



Passwords remain one of the most common attack vectors used by cybercriminals through phishing, credential stuffing, and password reuse attacks. Organizations require stronger authentication controls that align with Zero Trust security principles.



\## Solution



Microsoft Entra ID Authentication Strengths enable organizations to:



\* Enforce stronger authentication requirements.

\* Implement passwordless authentication.

\* Require phishing-resistant MFA.

\* Integrate authentication controls with Conditional Access.

\* Support Zero Trust identity protection strategies.



\## Security Benefits



\* Reduced phishing risk.

\* Reduced credential theft.

\* Improved account protection.

\* Enhanced administrator security.

\* Stronger identity verification.

\* Improved compliance and governance.



\## Business Benefits



\* Improved user experience.

\* Reduced password reset requests.

\* Lower operational support costs.

\* Increased security posture.

\* Better alignment with Zero Trust architecture.



\## Key Technologies



\* Microsoft Entra ID

\* Authentication Strengths

\* Conditional Access

\* Microsoft Authenticator

\* Windows Hello for Business

\* FIDO2 Security Keys

\* Passkeys



\## Conclusion



This project demonstrates how Authentication Strengths and Passwordless Authentication can be used to strengthen identity security, reduce password-related risks, and support modern Zero Trust security architectures within Microsoft Entra ID environments.
