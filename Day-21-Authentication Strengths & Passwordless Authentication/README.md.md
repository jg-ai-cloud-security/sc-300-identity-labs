\# SC-300 Day 21 – Authentication Strengths \& Passwordless Authentication



\## Overview



This project demonstrates how Microsoft Entra ID Authentication Strengths can be used to enforce stronger authentication methods and support a Zero Trust security model.



The implementation focuses on passwordless authentication, phishing-resistant MFA, FIDO2 Security Keys, Windows Hello for Business, Passkeys, and Conditional Access integration.



\## Objectives



\* Understand Authentication Strengths

\* Review Passwordless Authentication methods

\* Explore Phishing-Resistant MFA

\* Review FIDO2 Security Keys

\* Review Windows Hello for Business

\* Understand Passkeys

\* Review Conditional Access integration

\* Support Zero Trust Security principles



\## Business Scenario



DR Taxi is seeking to reduce identity-based attacks by implementing stronger authentication methods and reducing dependency on traditional passwords.



\## Technologies Used



\* Microsoft Entra ID

\* Conditional Access

\* Authentication Strengths

\* Microsoft Authenticator

\* FIDO2 Security Keys

\* Windows Hello for Business

\* Passkeys



\## Security Outcomes



\* Reduced phishing risk

\* Improved account protection

\* Stronger administrator security

\* Enhanced Zero Trust implementation

\* Improved identity governance
