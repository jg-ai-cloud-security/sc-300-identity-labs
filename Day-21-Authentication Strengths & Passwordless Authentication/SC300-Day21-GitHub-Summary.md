\# SC-300 Day 21 Summary



\## Topic



Authentication Strengths \& Passwordless Authentication



\## What I Learned



Today I explored how Microsoft Entra ID Authentication Strengths help organizations enforce stronger authentication requirements through Conditional Access.



I reviewed passwordless authentication technologies including Microsoft Authenticator, FIDO2 Security Keys, Windows Hello for Business, and Passkeys.



I also learned how phishing-resistant MFA provides stronger protection against credential theft and phishing attacks compared to traditional authentication methods.



\## Key Takeaways



\* Authentication Strengths provide granular control over authentication methods.

\* Passwordless authentication reduces password-related attacks.

\* FIDO2 Security Keys provide phishing-resistant authentication.

\* Windows Hello for Business supports secure passwordless sign-in.

\* Passkeys simplify secure authentication.

\* Conditional Access can enforce Authentication Strengths.

\* Zero Trust requires continuous identity verification.



\## Business Value



Implementing Authentication Strengths helps organizations improve identity security, reduce attack surface, and align with Zero Trust security principles.
