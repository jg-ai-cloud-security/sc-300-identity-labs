SC-300 Identity and Access Administrator — Hands-On Labs



This repository documents my hands-on learning journey for the Microsoft SC-300 Identity and Access Administrator certification.



The labs demonstrate practical identity and access management using Microsoft Entra ID, including user and group management, role-based access control (RBAC), authentication methods, and identity governance.



🔐 Skills Demonstrated



• Identity management with Microsoft Entra ID

• Role-Based Access Control (RBAC) implementation

• Authentication and access control (MFA, policies)

• Group-based access management

• Identity governance and security best practices



📂 Lab Structure



Each lab day contains the following documentation:



01-Concepts — Key identity and security concepts

02-Lab-Steps — Step-by-step lab instructions

03-Evidence — Screenshots of implementation

04-Identity-Queries — Identity-related queries and logs (future use)

05-Investigation — Identity analysis and observations

06-Architecture — Identity architecture diagrams

07-Azure-DevOps — Sprint tracking and documentation

08-Business-Case — Real-world business scenarios

09-SOP — Standard operating procedures

10-AI-Enhancements — AI-driven security insights

💰 Cost Hygiene



To avoid unnecessary charges:



Start with minimal configurations and expand gradually

Monitor identity-related services and licensing usage

Remove test users, roles, and configurations when no longer needed

Use least privilege to avoid over-provisioning

Clean up lab environments after completing exercises
