\# SC300 Day 01 — SOP (Identity Management)



\## Purpose

Define a standard process for managing identities in DR Taxi.



\---



\## User Creation



1\. Create user in Microsoft Entra ID

2\. Assign user to appropriate group

3\. Verify user details



\---



\## Group Assignment



\- Use groups to manage access

\- Add users based on job role

\- Avoid assigning access directly to users



\---



\## Role Assignment



\- Assign RBAC roles to users or groups

\- Use least privilege principle

\- Avoid Global Admin unless required



\---



\## Validation



\- Confirm users exist

\- Confirm group membership

\- Confirm roles are assigned correctly



\---



\## Security Best Practices



\- Centralise identity management

\- Use group-based access control

\- Apply least privilege

\- Follow Zero Trust principles



\---



\## Outcome

Secure and structured identity foundation for DR Taxi systems.
