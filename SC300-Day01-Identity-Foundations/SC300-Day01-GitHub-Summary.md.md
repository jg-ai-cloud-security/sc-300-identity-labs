\# SC300 Day 01 — Identity Foundation Summary



\## Business Context

DR Taxi requires secure identity and access control for booking, communication, and payment systems.



\---



\## What I Built

\- Users in Microsoft Entra ID

\- Security and Microsoft 365 groups

\- RBAC role assignments



\---



\## Security Focus

\- Identity as the first security layer

\- Least privilege access (RBAC)

\- Zero Trust principles



\---



\## Architecture

Users → Groups → Roles → Entra ID

\## Outcome

Successfully implemented a secure identity foundation aligned with real-world business requirements.
