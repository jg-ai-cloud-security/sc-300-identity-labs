\# SC300 Day 01 — Identity Foundation



\## Overview

Implemented identity foundation using Microsoft Entra ID with RBAC.



\---



\## What I Built



\- Created users in Entra ID

\- Created security and M365 groups

\- Assigned users to groups

\- Implemented RBAC roles (User Administrator, Global Reader)

\- Designed identity architecture

\- Documented business case (DR Taxi)

\- Tracked work using Azure DevOps sprint



\---



\## Key Concepts



\- Identity centralisation

\- Role-Based Access Control (RBAC)

\- Least privilege principle

\- Group-based access management



\---



\## What I Learned



Identity must be centrally managed and controlled using RBAC and least privilege to reduce risk and ensure secure access.



\---



\## Outcome



Successfully built a secure identity foundation aligned with real-world business requirements.
