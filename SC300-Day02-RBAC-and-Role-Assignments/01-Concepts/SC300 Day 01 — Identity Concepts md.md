\# SC300 Day 01 — Identity Concepts



\## Microsoft Identity Concepts — Comparison Table



| Concept | Definition | Purpose in Identity/Security | Key Capabilities |

|--------|-----------|-----------------------------|------------------|

| Microsoft Entra ID | Cloud-based identity platform | Centralises identity and access control | SSO, MFA, Conditional Access |

| Identity | Digital representation of user/service | Identifies who accesses resources | Users, service principals |

| Authentication | Verifies identity | Prevents unauthorised access | MFA, passwordless |

| Authorization | Determines access permissions | Controls what users can access | RBAC |

| Users | Individual identities | Represents access entities | Cloud, guest users |

| Groups | Collection of users | Simplifies access control | Security groups |

| RBAC | Role-based access control | Enforces least privilege | Built-in roles |

| Zero Trust | Verify every access request | Reduces attack surface | Least privilege |
