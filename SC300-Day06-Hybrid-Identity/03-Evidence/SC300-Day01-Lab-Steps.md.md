\# SC300 Day 01 — Lab Steps



\## Objective

Implement identity foundation using Microsoft Entra ID.



\---



\## Steps



1\. Access Microsoft Entra Admin Center

2\. Create users:

&#x20;  - user1

&#x20;  - user2

3\. Create groups:

&#x20;  - SG-IT-Users

&#x20;  - M365-Team

4\. Add users to groups

5\. Assign roles:

&#x20;  - User Administrator → user1

&#x20;  - Global Reader → user2



\---



\## Validation



\- Users created successfully

\- Groups contain users

\- Roles assigned correctly
